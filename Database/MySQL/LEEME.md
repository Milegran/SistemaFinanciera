# Base de datos actual de CapitalWest

Use **CapitalWest/CapitalWest.sql**. Está diseñada con Proyecto No. 2 DS8.pdf y el documento de pantallas, y validada en MariaDB 10.4.32.

Las instrucciones completas, modelos y diccionario están en la carpeta **CapitalWest**. Crea una base nueva llamada **capitalwest**, con 40 tablas, 15 vistas y dos triggers. Importe una sola vez en una base vacía.

SistemaFinanciera.sql y LEEME_version_anterior.md se conservan como versión anterior. La aplicación VB.NET aún utiliza SQL Server.
